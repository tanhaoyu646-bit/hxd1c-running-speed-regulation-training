# HXD1C 途中调速实操考评

这是从既有 HXD1C 机座素材派生出的独立项目。项目只有考评模式，包含：

- 途中一段制动调速
- 途中两段制动调速

## 运行

在项目目录执行：

```powershell
npm run serve
```

然后访问 `http://127.0.0.1:4187/`。项目必须通过 HTTP 服务打开，不能直接双击 HTML；三维线路资源使用浏览器 `fetch()` 加载。

## 学生操作

- 首次进入先填写姓名和学号；信息仅保存在当前浏览器标签页，每次技能考评生成独立的考生场次。
- 拖动驾驶台牵引手柄、自阀和单阀完成操纵；点击状态框也可逐级换位。
- 手机横屏可打开“操作”面板，用大按钮逐级调节牵引／电制动、自阀和单阀，也可直接打开 LKJ、CIR；速度随级位、坡度、阻力及制动力逐步响应，不按级位直接跳到固定速度。
- 点击“单缓”完成机车单独缓解状态切换。
- 点击驾驶台中央实物 LKJ 屏幕，LKJ 会停靠在驾驶台左上区域；桌面端不遮挡主要操纵装置，移动端横屏显示大窗。
- 使用“呼唤确认”记录当前信号呼唤；系统不显示下一步答案。
- LKJ 的报警、卸载、常用制动和紧急制动会作用于列车动力学，不是只改文字。
- 驾驶台原位数字速度、限速、时钟、速度和风压指针、网压与牵引电流条随同一仿真状态实时变化；LKJ 放大界面支持查询、记录翻阅、报警确认与满足条件后的制动缓解。
- 原机座的警惕复位、机车信号查看、按住鸣笛和 CIR 入口已恢复。CIR 复用既有项目的完整原模拟器，列尾风压与本轮列车管状态联动，支持列尾连接后的风压查询和通信按键记录；不连接真实无线通信。
- 考评进度参考过分相项目的编号与状态样式，只有按顺序完成的操作才计入完成数；顺序记录不完整时本轮成绩不能合格。
- 通过进站信号机后继续在站内运行 600 m，再统一结算成绩；普通失误扣分，LKJ 常用/紧急制动或进站超速属于安全红线。
- 成绩单显示本轮考生姓名、学号、开始时间和完成时间，并可切换考生重新登记。

## 线路环境

- 两个技能使用内江—宜宾线路约 `23.5–32.05 km` 的独立场景窗口，包含原线路、邻线、桥梁、隧道、地形、树木、建筑和接触网等环境对象。
- 项目内置 `neiyi-speed-regulation-terrain.json`，运行时不依赖其他训练项目目录。
- 全部10块地形均通过 Open Rails 解析器从原 `NEIYI` 线路 `.t` 与 `_y.raw` 文件导出，分辨率为129×129；不再使用推算地形。
- 本务线由原 `TrackDB` 中心线连续重建，消除原分节轨道姿态与高程不一致造成的跳坡、埋轨和断轨；原桥梁模型的梁体两端按该中心线高程校准，桥墩顶部随梁体移动。隧道、接触网及约 5 米外邻线仍保留原世界块场景。
- 原数据中唯一的单节约 `52‰` 异常坡段已在后续 1.8 km 内平滑分摊，并在一段制动考核起点前回归原高程。
- 前向驾驶视角采用同机座“途中瞭望、坡道操纵、站内停车”项目一致的 `-0.22 rad` 下俯基准，并在此基础上跟随实际线路坡度，保证轨道位于挡风玻璃有效观察区。
- 页面打开后即在姓名、学号填写阶段后台构建线路场景，选择技能时只切换考评起点和信号配置。

## 内容依据

实操时序按照下列课程素材建模，但微课视频不嵌入考评页面：

- `D:/cxdownload/3.4.3技能点3途中一段制动调速.mp4`
- `D:/cxdownload/3.4.2 技能点2 途中两段制动调速（数字人）.mp4`
- 既有项目中的操规、课程标准、LKJ2000 界面和线路素材

一段制动的模型重点是：从进站前第二架通过信号机外方开始，依次经过两架通过信号机；空气制动时保持初始 11 级并实施单缓，制动作用稳定 5 s 后退至 4 级目标级位，减速不足时追加减压，并在进站信号机处控制速度不超过 45 km/h，进站后继续运行 600 m。

两段制动的模型重点是：第一次制动时保持 11 级并单缓，作用稳定后退至 9 级，约 93 km/h 缓解、列车管充分充至接近 600 kPa；第二次制动时保持 9 级并单缓，作用稳定后退至 4 级，进站信号机处约 40 km/h 且不超过 45 km/h，进站后继续运行 600 m。

牵引主手柄与坡道驾驶调速项目采用同一给定逻辑：1—12 级分别对应 10—120 km/h目标速度；达到或超过当前级位给定速度时切除牵引输出，低于给定速度时由坡度、阻力和恒功率包络共同决定实际牵引力与平衡速度。

## 独立性

- 独立目录、独立 Git 仓库、独立包名与服务端口 `4187`。
- 本项目不引用旧项目的相对路径，运行时不写入旧项目。
- 浏览器存储键使用 `hxd1c-running-speed-regulation-v1` 前缀。
- 考生信息使用本项目独立的 `sessionStorage` 键，只在当前标签页内保留。
- 两个技能的每次考评均创建新的状态对象，事件、样本和评分不会互相复用。
